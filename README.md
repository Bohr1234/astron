# ASTRON
### An Orbital Mechanics & Physics Engine in Python

A Python-based simulation engine for calculating orbital mechanics, rocket propulsion, and visualizing 2D trajectories, integrated with the Gemini API to answer astrophysical questions.

## Features
* **Astrodynamics & Physics Constants:** Built-in standard physical constants for Earth.
* **Rocket Equations:** Calculates delta-v and dry mass constraints.
* **Orbital Calculations:** Computes circular orbital speeds at given altitudes.
* **Trajectory Plotting:** Generates 2D trajectory visualizations using Matplotlib.
* **AI Integration:** Uses the Gemini API for real-time natural language query support on spaceflight physics.
